# Електронний журнал ліцею «Віват»

Демонстраційний React-проєкт українською мовою. Усі навчальні записи вигадані.

## Запуск на комп’ютері

Потрібен Node.js (LTS).

```bash
npm install
npm run dev
```

Відкрий адресу, яку покаже термінал (зазвичай http://localhost:5173).

## Підготовка до публікації

```bash
npm install
npm run build
```

Після успішної збірки готові статичні файли будуть у папці `dist`.

### Публікація на Vercel

1. Завантаж цей проєкт у власний репозиторій GitHub.
2. На Vercel натисни **Add New → Project** і вибери репозиторій.
3. Framework: **Vite** (або автоматичне визначення).
4. Build Command: `npm run build`.
5. Output Directory: `dist`.
6. Натисни **Deploy**.

### Публікація на Netlify

1. Завантаж проєкт у GitHub.
2. На Netlify створи новий сайт із Git-репозиторію.
3. Build command: `npm run build`.
4. Publish directory: `dist`.
5. Запусти публікацію.
